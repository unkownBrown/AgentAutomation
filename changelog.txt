Version 10
- New CMD menu: type AgentWrzy and pick with the arrow keys. Settings (approvals, language, theme, models), model test, and more.
- The AgentWrzy command works from any CMD window. Auto-update now includes the launcher script.
- Multi-language: common commands are understood in 15 languages without AI, and the AI replies in yours. UI: Indonesian or English (/bahasa).
- Smarter: remembers your preferences (/ingat, /memori), knows the page you have open, multi-step tasks use a smart model (/model smart).
- Faster: backup request when a model is slow, leaner prompt, shorter answers.
- General abilities: open any app, kill any process, run PowerShell, power (shutdown/restart/sleep/lock), brightness, weather, calculator, tidy folders.
- Color theme v2: /tema orange, cyan, green, purple, pink, gold, mono.

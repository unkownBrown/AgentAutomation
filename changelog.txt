Version 12
- NEW: understand apps/websites (inspect_app, inspect_site) — version, publisher, digital signature, DLLs, network traffic. For curiosity and debugging, not for bypassing licensing, cheating, or breaking into someone else's system.
- NEW: your own macros. /macro add name = step1 ; step2, then just type the name to run every step in order.
- NEW: /doctor for a full diagnostic (router, model, browser, update, write permission) in one report ready to paste into a GitHub Issue.
- NEW: /bagikan shows the one-line install command and repo link, easy to share with friends.
- Version 11: automatic language that follows what you type, in 22 languages.
